# Tech stack

| Part     | Technology                         | Why |
| -------- | ---------------------------------- | --- |
| Frontend | Next.js + TypeScript + Tailwind CSS | Popular React framework, typed code, fast styling |
| Backend  | FastAPI (Python), managed with uv  | Same language as the ML code, automatic API docs |
| Database | PostgreSQL (planned)               | Reliable relational database |
| ML       | PyTorch, Kraken / TrOCR (planned)  | Standard deep learning library and pretrained handwriting models, see [AI model research](ai-model-research.md) |
| Tooling  | ESLint, Prettier, Ruff, pytest     | Consistent code style and automated tests |
| Workflow | Husky, commitlint, GitHub Actions  | Checked commit messages and automatic checks on every pull request |
